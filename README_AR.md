## 🚀 البداية السريعة

### مستخدمو ويندوز (برنامج التثبيت موصى به)

1. قم بتنزيل `PasswordGenerator-3.0.0-Setup.exe`
2. انقر نقراً مزدوجاً لتشغيل برنامج التثبيت
3. اختر مجلد التثبيت، ✅ حدد "إنشاء اختصار سطح المكتب"
4. بعد التثبيت، انقر نقراً مزدوجاً على أيقونة سطح المكتب للتشغيل!

> 💡 أو قم بتنزيل الإصدار المحمول ZIP، فك الضغط وانقر نقراً مزدوجاً على `PasswordGenerator.hta`

### مستخدمو ماك

**تطبيق GUI:**
1. قم بتنزيل `PasswordGenerator-3.0.0-macOS.dmg`
2. افتح DMG، اسحب التطبيق إلى Applications
3. انقر نقراً مزدوجاً للتشغيل، **تفتح نافذة أصلية مباشرة، بدون متصفح!**

**سطر الأوامر:**
```bash
chmod +x pwgen
./pwgen
```

### مستخدمو لينكس

```bash
chmod +x pwgen-linux
./pwgen-linux
```

أو استخدم الإصدار عبر الإنترنت مباشرة!

## 📥 ميزة تصدير السجل

يتم حفظ كلمات المرور المولدة تلقائياً في السجل المحلي. التصدير بعدة صيغ:

| الصيغة | الوصف |
|--------|-------|
| 📄 **TXT** | نص عادي، كلمة مرور واحدة لكل سطر |
| 📋 **JSON** | بيانات منظمة مع كلمة المرور والطول والإنتروبيا |
| 📊 **CSV** | صيغة جدول، متوافقة مع Excel |
| 📝 **Markdown** | جدول منسق للتوثيق |

**كيفية الاستخدام:**
1. انقر على زر "⬇️ تنزيل" في قسم السجل
2. اختر الصيغة المطلوبة
3. أكد للتنزيل

## 📖 دليل استخدام سطر الأوامر

### الاستخدام الأساسي

```bash
# الوضع التفاعلي (موصى به للمبتدئين)
pwgen

# توليد كلمة مرور بطول محدد (8-128)
pwgen -l 16
pwgen -l 128    # الحد الأقصى 128 حرفاً

# توليد عدة كلمات مرور دفعة واحدة
pwgen -l 20 -c 5 -b

# استبعاد الأحرف المتشابهة
pwgen -l 16 -e
```

### جميع المعلمات

| المعلمة | الشكل الكامل | الوصف | الافتراضي |
|---------|--------------|-------|-----------|
| `-l` | `--length` | طول كلمة المرور (8-128) | 12 |
| `-c` | `--count` | عدد التوليد | 3 |
| `-e` | `--exclude` | استبعاد الأحرف المتشابهة | لا |
| `-b` | `--batch` | وضع الدفعة | لا |
| | `--no-upper` | بدون أحرف كبيرة | لا |
| | `--no-lower` | بدون أحرف صغيرة | لا |
| | `--no-digits` | بدون أرقام | لا |
| | `--no-special` | بدون رموز خاصة | لا |
| | `--json` | إخراج بتنسيق JSON | لا |
| | `--plain` | إخراج نص عادي | لا |
| `-h` | `--help` | عرض المساعدة | - |
| | `--save-encrypted` | تشفير وحفظ كلمات المرور محلياً | لا |
| | `--read-encrypted` | فك تشفير وقراءة كلمات المرور المحفوظة | لا |
| | `--search` | تصفية الخزنة المشفرة بالكلمات المفتاحية | - |
| | `--sync-push` | رفع الملف المشفر إلى خادم SFTP | لا |
| | `--sync-pull` | تنزيل الملف المشفر من خادم SFTP | لا |
| | `--force` | مزامنة إجبارية، تخطي مقارنة الطابع الزمني | لا |
| | `--history` | عرض سجل التوليد | لا |
| | `--no-history` | عدم الحفظ في السجل | لا |

### أمثلة التخزين المشفر

```bash
# توليد جماعي وحفظ مشفر
pwgen -b -l 16 -c 3 --save-encrypted

# فك التشفير والقراءة (كلمات المرور مخفية افتراضياً، أدخل الرقم للكشف)
pwgen --read-encrypted

# فك التشفير والتصفية بالكلمات المفتاحية
pwgen --read-encrypted --search "قوي"
```

### مزامنة SFTP السحابية

1. انسخ `.env.example` إلى `.env` وأدخل معلومات الخادم
2. أوامر المزامنة:

```bash
# رفع يدوي
pwgen --sync-push

# تنزيل يدوي
pwgen --sync-pull

# رفع إجباري (تخطي مقارنة الطابع الزمني)
pwgen --sync-push --force
```

## 🔒 مستويات قوة كلمة المرور

| المستوى | الأيقونة | الإنتروبيا (bits) | وقت الاختراق المقدر |
|---------|----------|-------------------|---------------------|
| ضعيف جداً | 🔴 | < 28 | فوري |
| ضعيف | 🟠 | 28-36 | ساعات |
| متوسط | 🟡 | 36-60 | أيام إلى أشهر |
| قوي | 🟢 | 60-80 | سنوات إلى قرون |
| قوي جداً | 🔵 | 80-100 | آلاف السنين |
| قوي للغاية | 🟣 | > 100 | عمر الكون |

> 💡 **توصية:** استخدم 16 حرفاً أو أكثر مع إنتروبيا 80+ للحسابات المهمة

## 🏗️ البنية التقنية

تم تنفيذ هذا المشروع بعدة لغات برمجة لمنصات مختلفة:

```
password-generator/
├── docs/                    # إصدار الويب (GitHub Pages)
│   └── index.html
├── app/                     # تطبيقات سطح المكتب
│   ├── PasswordGenerator.hta    # Windows GUI (HTA)
│   ├── pwgen.html              # واجهة HTML عامة
│   └── 启动密码生成器.bat
├── generate-password.py     # إصدار Python
├── generate-password.js     # إصدار Node.js
├── generate-password.swift  # إصدار Swift
└── dist/                    # مخرجات البناء
```

### ملاحظات الأمان

- **إصدار الويب**: يستخدم `crypto.getRandomValues()` Web Crypto API + AES-GCM + PBKDF2
- **إصدار Python**: يستخدم وحدة `secrets` + Fernet (AES) + PBKDF2HMAC
- **إصدار Swift**: يستخدم عشوائية آمنة على مستوى النظام
- **إصدار Node.js**: يستخدم `crypto.randomInt()`

تستخدم جميع الإصدارات مولدات أرقام عشوائية آمنة تشفيرياً لضمان عشوائية كافية.
